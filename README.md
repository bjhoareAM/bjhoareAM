# kia ora ra 👾

I’m passionate about **digital collections, data partnerships, and open access projects**.  
I am employed at **Auckland Museum**, and my role allows me to engage with digital partnership platforms via large-scale batch uploads and ongoing data maintenance.  
My interests include **metadata governance**, **digital preservation**, **data visualisations**, **linked open data**, and building tools to support GLAM institutions' contributions of open access content.

## Current Projects
- Building bespoke Wikimedia Commons upload templates (`AWMMHumanHistory`, `AWMMDocumentaryHeritage`, `AWMMNaturalSciences`)  
- Developing **PattyPrepper**: a Toolforge tool to prepare metadata schemas for Commons uploads in conjunction with **PattyPan** 
- Experimenting with machine learning models for automated image descriptions and subject tagging
- GLAM Tool Hospital: a community hub that supports the health, documentation, and sustainability of tools used in GLAM Wiki workflows. A natural language stepped-through form helps users file bug reports or request new features for tools in their GLAM profession's workflows, and these are lodged via the Phabricator (task management for Wiki developers and technical contributors) API to increase communication between users and developers of these tools. Read more here: https://meta.wikimedia.org/wiki/User:Dactylantha/GLAM_Tool_Hospital. Try out the tool here: https://glam-tool-hospital.toolforge.org/
- Developing a Natural Science Data model for standardised (non-canonical) specimen/occurrence uploads onto Wikidata and Wikimedia Common, in collaboration with User:Ambrosia10 during her Wikimedian in Residence position at Bioeconomy Science Institute. Read more here: https://www.wikidata.org/wiki/Wikidata:WikiProject_Natural_History_Specimen_Data_Model.
